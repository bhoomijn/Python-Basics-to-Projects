## About

This repository contains small exercises and mini projects to help you move from Python basics to real projects. Each folder focuses on a topic and includes clear examples, explanations, and runnable code.

## Repository Structure

- Exercises: Topic-focused practice files (Functions, Loops, Conditionals, Data Structures, String Operations, File Handling)
- Mini Projects: Small real-world projects that combine multiple concepts (e.g., Snake-Water-Gun game, Calculator, File Processing Utilities)

## Quickstart

1. Clone the repository

```bash
git clone https://github.com/bhoomijn/python-basics-to-projects.git
cd python-basics-to-projects
```

2. (Optional) Create a virtual environment and install dependencies

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt  # if provided
```

3. Run any example

```bash
python path/to/example.py
```

## Recommended Learning Flow

1. Start with Exercises for each topic to build fundamentals.
2. Move to Mini Projects to practice integrating concepts.
3. Add tests or improve projects as a learning exercise.

## Contributing

Contributions are welcome! A few guidelines:

- Fork the repository and open a pull request against `main`.
- Keep changes small and focused (one feature/fix per PR).
- If you add external dependencies, update `requirements.txt` and explain why.
- Add tests where applicable in a `tests/` folder.

## Code Quality

This repo follows common best practices:

- PEP 8 style guidelines
- Meaningful variable names and docstrings
- Try/except for error handling where appropriate
